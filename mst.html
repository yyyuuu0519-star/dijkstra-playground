MINIMUM SPANNING TREE, STEP BY STEP

      你會學到什麼

      • 最小生成樹的定義——全部連通、沒有環、V−1 條邊、總重最小。
      • Kruskal——邊由小到大排序，一條一條看，會成環就跳過。
      • 併查集——用 find 找老大，判斷兩端是不是已經同一組；union 把兩組接起來。
      • Prim——從一個頂點長出去，每次接上離目前這棵樹最便宜的邊。
      • 切割性質——跨越目前樹與外部的最輕邊，可以安全地加入 MST。
      • 平手與不連通——最小生成樹可能不只一棵；不連通的圖只能得到最小生成森林。
      建議順序

      第 1 關 Kruskal → 第 2 關 Prim（同一張圖，總重一樣但收邊順序不同）→ 第 3 關換起點 → 第 4 關看平手 → 第 5 關一直成環 → 第 6 關不連通。

      THE IDEA IN CODE

      兩種走法，同一個目標。

      Kruskal O(E log E)
      minimum-spanning-treePSEUDOCODE
      // Kruskal：先看最便宜的邊，避免成環
sort(edges, by weight)
for each edge (u, v, weight):
    if find(u) != find(v):
        union(u, v)
        mst.add((u, v, weight))
    else: skip // 這條邊會形成環

// Prim：每次從目前樹跨出去，接最便宜的一條邊
tree = {start}
while tree does not contain every vertex:
    edge = minimum edge crossing (tree, outside)
    tree.add(edge.other_endpoint)
    mst.add(edge)

      Kruskal 從「邊」出發，Prim 從「點」長出去。兩條路，都通往最小生成樹。
