# Dijkstra 資料結構遊戲場

以互動加權地圖逐步展示 Dijkstra 最短路徑與 Kruskal／Prim 最小生成樹的繁體中文教學網站。

## 使用方式

直接用瀏覽器開啟 `index.html`（Dijkstra）或 `mst.html`（Kruskal／Prim）即可遊玩，不需要安裝依賴或啟動伺服器。

## 專案檔案

- `index.html`：頁面內容與操作介面
- `style.css`：深色主題與響應式版面
- `app.js`：圖形資料、演算法步驟與互動邏輯
- `mst.html`：Kruskal／Prim 最小生成樹教學頁面
- `mst.css`：最小生成樹頁面的深色主題與響應式版面
- `mst.js`：最小生成樹關卡、演算法步驟與互動邏輯
